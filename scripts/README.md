# Scripts Directory

This directory contains organized copies of the main scripts for development and operational purposes. The authoritative versions of the main scripts remain in the root directory for easy access and traditional usage.

## Directory Structure

- `deployment/` - Scripts for deploying the application
- `database/` - Scripts for database management
- `development/` - Scripts for development workflows

## Authoritative Scripts Location

The authoritative versions of the main operation scripts are located in the root directory:
- `setup_full_stack.sh` - Main setup script to start the full application stack
- `start_dev_services.sh` - Start development services using Docker
- `stop_services.sh` - Stop all running services
- `start_nginx.sh` - Start nginx reverse proxy

This organization keeps the root directory clean while maintaining the accessibility of critical scripts from the root level as expected by users and documentation.

## Purpose

The scripts in this directory are organized by function for maintenance and development purposes, but the root directory versions are the ones intended for direct user interaction.
